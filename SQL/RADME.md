# 🗄️ SQL Learning Roadmap

> My personal SQL knowledge base for Backend Development (MERN + MySQL/PostgreSQL)

---

# 🎯 Goal

Learn SQL from beginner to backend engineer level.

By the end of this roadmap, I should be able to:

* Design relational databases
* Write clean and optimized SQL queries
* Understand relationships and joins
* Use aggregate and window functions
* Build backend APIs using SQL
* Write transaction-safe queries
* Optimize queries using indexes
* Solve SQL interview problems confidently

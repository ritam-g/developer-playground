# 📖 Introduction

The `IN` operator is used to check whether a value matches **any value in a list**.

Instead of writing multiple `OR` conditions, you can use `IN` to make your query shorter and easier to read.

---

# 🤔 Why Do We Need IN?

Imagine you want to find users from **Delhi**, **Mumbai**, or **Kolkata**.

Without `IN`:

```sql
SELECT *
FROM users
WHERE city = 'Delhi'
OR city = 'Mumbai'
OR city = 'Kolkata';
```

With `IN`:

```sql
SELECT *
FROM users
WHERE city IN ('Delhi', 'Mumbai', 'Kolkata');
```

The second query is much cleaner.

---

# 📝 Syntax

```sql
SELECT column_name
FROM table_name
WHERE column_name IN (value1, value2, value3);
```

---

### Using NOT IN

```sql
SELECT *
FROM table_name
WHERE column_name NOT IN (value1, value2);
```

---

# 🔑 Keyword Explanation

## IN

Checks whether a value exists in the given list.

---

## NOT IN

Checks whether a value does **not** exist in the given list.

---

# ⚠️ Common Mistakes

### ❌ Using = Instead of IN

Wrong

```sql
WHERE city = ('Delhi','Mumbai');
```

Correct

```sql
WHERE city IN ('Delhi','Mumbai');
```

---

### ❌ Forgetting Quotes

Wrong

```sql
WHERE city IN (Delhi, Mumbai);
```

Correct

```sql
WHERE city IN ('Delhi','Mumbai');
```

---

### ❌ Using Multiple OR Instead of IN

Works:

```sql
WHERE city='Delhi'
OR city='Mumbai'
OR city='Kolkata';
```

Better:

```sql
WHERE city IN ('Delhi','Mumbai','Kolkata');
```

---

# 💡 Best Practices

* Use `IN` instead of many `OR` conditions.
* Use `NOT IN` when excluding multiple values.
* Keep the list readable by placing one value per line if it becomes long.

Example:

```sql
WHERE city IN (
    'Delhi',
    'Mumbai',
    'Kolkata',
    'Pune'
);
```

# 🎤 Interview Questions

### What is the purpose of IN?

It checks whether a value exists in a list of values.

---

### What is the difference between IN and OR?

Both can return the same result, but `IN` is cleaner and easier to read when checking multiple values.

---

### What does NOT IN do?

It excludes rows whose values are present in the given list.

# 📌 Summary

* `IN` checks if a value exists in a list.
* `NOT IN` excludes values from a list.
* `IN` is a cleaner alternative to multiple `OR` conditions.
* Strings should be enclosed in single quotes.


# PRIMARY KEY

> **Module:** SQL Basics
> **Topic No:** 06
> **Status:** ✅ Completed

# 📖 Introduction

A **PRIMARY KEY** is a column (or a combination of columns) that **uniquely identifies each row** in a table.

Think of it as a person's Aadhaar Number or Passport Number.

Even if two people have the same name, they cannot have the same Aadhaar number.

Similarly, every row in a table must have a unique Primary Key.

---

# 🤔 Why Do We Need PRIMARY KEY?

Imagine a `users` table:

| id | name  | city    |
| -- | ----- | ------- |
| 1  | Rahul | Delhi   |
| 2  | Rahul | Mumbai  |
| 3  | Rahul | Kolkata |

If you search by name:

```sql
SELECT *
FROM users
WHERE name = 'Rahul';
```

You'll get **three rows**.

But if you search by `id`:

```sql
SELECT *
FROM users
WHERE id = 2;
```

You'll get exactly **one row**.

That's why we use a Primary Key.

---

# 📝 Syntax

### While Creating a Table

```sql
CREATE TABLE users (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(100),
    age INT,
    city VARCHAR(50)
);
```

---

### Add PRIMARY KEY Later

```sql
ALTER TABLE users
ADD PRIMARY KEY (id);
```

---

# 🔑 Keyword Explanation

## PRIMARY

Means the **main** identifier.

---

## KEY

Means a column used to identify records.

Together,

`PRIMARY KEY`

means:

> The main column used to uniquely identify every row.

---

# ⭐ Rules of PRIMARY KEY

A Primary Key:

* Must be **unique**
* Cannot contain **NULL**
* There can be only **one Primary Key** per table
* Can consist of multiple columns (Composite Primary Key)

---

# 💻 Examples

### Create Users Table

```sql
CREATE TABLE users (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(100)
);
```

---

### Insert Valid Data

```sql
INSERT INTO users
VALUES
(1,'Rahul','rahul@gmail.com'),
(2,'John','john@gmail.com');
```

Works successfully.

---

### Insert Duplicate Primary Key

```sql
INSERT INTO users
VALUES
(1,'Alice','alice@gmail.com');
```

❌ Error

```
Duplicate entry '1' for key 'PRIMARY'
```

Because `id = 1` already exists.

---

### Insert NULL

```sql
INSERT INTO users
VALUES
(NULL,'David','david@gmail.com');
```

❌ Error

A Primary Key cannot be NULL.

---

# 🌍 Real Backend Example

Suppose a user updates their profile.

Backend receives:

```json
{
    "id": 5,
    "city": "Bangalore"
}
```

Backend query:

```sql
UPDATE users
SET city = 'Bangalore'
WHERE id = 5;
```

The Primary Key ensures that only **one user** is updated.

---

# ⚠️ Common Mistakes

### ❌ Duplicate ID

```sql
INSERT INTO users
VALUES
(1,'Emma','emma@gmail.com');
```

If `id = 1` already exists, MySQL throws an error.

---

### ❌ NULL Primary Key

```sql
INSERT INTO users
VALUES
(NULL,'John','john@gmail.com');
```

Not allowed.

---

### ❌ Using Name as Primary Key

```sql
name VARCHAR(100) PRIMARY KEY
```

Bad idea because many users can have the same name.

Always prefer an ID.

---

# 💡 Best Practices

* Use an integer `id` as the Primary Key.
* Combine it with `AUTO_INCREMENT` (you'll learn this later).
* Never update the Primary Key unless absolutely necessary.
* Every table should have a Primary Key.

---

# 🎤 Interview Questions

### What is a Primary Key?

A column that uniquely identifies each row in a table.

---

### Can a Primary Key contain NULL?

No.

---

### Can two rows have the same Primary Key value?

No.

---

### Can a table have multiple Primary Keys?

No.

A table can have only **one** Primary Key, though it can be made up of multiple columns (composite key).

# 📌 Summary

* A Primary Key uniquely identifies each row.
* It must be unique.
* It cannot contain NULL.
* Every table should have one Primary Key.
* Primary Keys are commonly named `id`.
